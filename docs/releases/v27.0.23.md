# WeightMaster v27.0.23

This patch updates the Station 1 bill-number shortcut from N to M.

- Press M to focus the bill-number field and select its current value.
- Enter a number, then press Enter to return to the member-number/barcode field.
- Keep the current weight and other round values unchanged.
- N no longer activates this shortcut.
- Retain all fixes from v27.0.22, including the fresh-round reset and newest-first table.

## Installation

Close WeightMaster and back up the local database before replacing the executable.
Choose the download matching the Windows architecture and keep existing configuration files.

## Verification

Automated checks cover M from each round step, Enter returning to member entry,
N not activating the shortcut, modifiers, repeated keys, busy saves and Station 2 isolation.
Both Windows builds run these checks before publishing. Physical-scale and WPF
acceptance testing on the weighing machine is still required.
