# WeightMaster v27.0.27

## Station 1

- Hide the upper member-turn table and let the line-wise table use the full right-hand area. Its scrolling rows and line/all-line totals remain in place.
- Accept only 1-5 ASCII digits in the member-number field. Reject invalid typing, paste, drag-and-drop and scanner values without a dialog.
- Keep final Confirm disabled until both a scale reading and a valid member number are present. The Enter-key flow cannot bypass this check.
- Preserve v27.0.26's retained supervisor, transport line and bill number, as well as its failed-save retry behavior.

No database schema or Tea Coop API contract changes are required.

## Installation

Close WeightMaster and back up the branch-local database before upgrading. Download the executable matching the Windows architecture, replace the old executable, and keep the existing configuration files.

## Verification

The release workflow runs Station 1 regression checks and builds both Windows architectures. Test a complete weighing, a malformed barcode scan and the scale connection on a station PC before broad rollout.
