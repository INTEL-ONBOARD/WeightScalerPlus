# WeightMaster v27.0.24

## Station 1

- Keep the selected supervisor, transport line and entered bill number after a successful Confirm.
- Keep these fields editable; use the operator's updated values for the next save.
- Continue clearing the member, sack/box counts, weights and deductions for the next round.
- Keep the logged-in weighing officer unchanged.
- Preserve the M bill-number shortcut, newest-first table and scale zero-return interlock.
- Prevent delayed line lookups from overwriting the retained bill after a save.

Manual Clear and a fresh login still reset supervisor, line and bill. A failed
save keeps all inputs, as before. No database schema changes are introduced.

## Installation

Close WeightMaster and back up the local database before replacing the executable.
Choose the download matching the Windows architecture and keep the existing
configuration files.

## Verification

Automated checks cover two consecutive Enter-driven rounds without reselecting
the three fields, editing them for the next round, stale bill lookup responses,
manual Clear, duplicate submissions, failed saves, the M shortcut and table sorting.
Both Windows builds run the checks before publishing. Physical-scale and WPF
acceptance testing on the weighing machine is still required.
