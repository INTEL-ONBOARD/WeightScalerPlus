# WeightMaster v27.0.22

Based on v27.0.21, retaining its cloud mirror, reporting and Station 2 fixes.

## Station 1

- Start each saved round with a fresh member, line, supervisor and bill number.
- Restore the Enter-driven workflow without requiring a mouse click on Reset.
- Focus Confirm explicitly and prevent duplicate Enter submissions during saving.
- Ignore stale member and line lookups after a round is reset.
- Show newest transactions first while retaining chronological member round numbers and totals.
- Press N to select the bill-number field. Enter there returns to the member-number/barcode field without saving or clearing other round values.
- Preserve unregistered-member support and production save diagnostics.
- Keep inputs after a failed save and report that some records may already exist.

## Installation

Close WeightMaster and back up the local database before upgrading. Replace only
the executable with the download matching the Windows architecture. Keep the
existing configuration files in the same directory. The executables are
self-contained and do not require a separate .NET installation.

## Verification

The release workflow runs headless Station 1 regression checks before publishing
both Windows architectures. These checks do not replace an acceptance test on
the Windows weighing machine with its physical scale and barcode scanner.

Saving still uses the existing multi-record persistence path, not one atomic
database transaction. Check existing records before retrying a partially failed save.
